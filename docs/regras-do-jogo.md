# Regras do jogo

## Participantes e cartas

- A partida acontece entre o jogador e a máquina.
- Cada rodada usa uma carta para cada participante.
- As cartas são sorteadas sem reposição: uma carta usada não volta para o monte durante a partida.
- A versão inicial terá 14 cartas, distribuídas em 7 rodadas.

## Como funciona uma rodada

1. O jogador e a máquina recebem uma carta.
2. O jogador escolhe um atributo da própria carta: ataque, defesa ou magia.
3. O valor desse atributo é comparado com o mesmo atributo da carta da máquina.
4. Os dois valores são revelados e a pontuação da rodada é atribuída.

## Pontuação

| Resultado da comparação | Pontos do jogador | Pontos da máquina |
| --- | ---: | ---: |
| Jogador tem o maior valor | 3 | 0 |
| Máquina tem o maior valor | 0 | 3 |
| Os valores são iguais | 1 | 1 |

## Fim da partida

- A partida termina depois que todas as cartas forem usadas.
- Vence quem acumular mais pontos.
- Se os participantes terminarem com a mesma pontuação, a partida termina empatada.
