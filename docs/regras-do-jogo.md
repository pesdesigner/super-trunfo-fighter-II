# Regras do jogo

## Participantes e cartas

- A partida acontece entre o jogador e a máquina.
- Cada rodada usa uma carta para cada participante.
- Há 20 personagens no baralho. Kage fica reservado para a habilidade especial.
- As cartas normais são embaralhadas e distribuídas sem reposição. Uma carta usada não volta para o monte.
- Cada partida tem até 7 rodadas e usa 14 cartas normais; as cartas que sobrarem não são usadas naquela partida.

## Como funciona uma rodada

1. O jogador e a máquina recebem uma carta.
2. O jogador escolhe um atributo da própria carta: ataque, defesa ou magia.
3. O valor desse atributo é comparado com o mesmo atributo da carta da máquina.
4. Os dois valores são revelados e a pontuação da rodada é atribuída.

## Pontuação

| Resultado da comparação | Pontos do jogador | Pontos da máquina |
| --- | ---: | ---: |
| Jogador vence com carta normal | 3 | 0 |
| Máquina vence com carta normal | 0 | 3 |
| O portador de Akuma vence | 4 para quem venceu | 0 |
| Os valores são iguais | 1 | 1 |

Akuma é uma única carta coringa no baralho normal, portanto pode aparecer no máximo uma vez por partida. Se empatar, cada participante recebe 1 ponto normalmente.

## Sequência de vitórias e Kage

- Uma vitória aumenta a sequência consecutiva de quem venceu e zera a sequência do adversário.
- Empate zera as sequências dos dois lados.
- Ao vencer 3 rodadas seguidas, o participante recebe Kage para usar na rodada seguinte, no lugar da carta normal que receberia.
- Jogador e máquina têm recompensas independentes: cada lado pode receber e usar Kage uma vez na partida.
- Kage fica fora do monte normal. Se a sequência de três vitórias acontecer na última rodada, não há rodada seguinte para receber a carta.

## Fim da partida

- A partida termina após até 7 rodadas.
- Vence quem acumular mais pontos.
- Se os participantes terminarem com a mesma pontuação, a partida termina empatada.
- O popup final mostra o resultado e o placar. O botão **Continuar** inicia uma nova partida; se a contagem regressiva acabar, aparece **GAME OVER** e o jogo retorna à tela inicial.
